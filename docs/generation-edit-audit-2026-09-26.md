## Причины и исправления

| Обращение | Проверка | Исправление |
|---|---|---|
| Добавление бани возвращает к началу | На сохранённом серверном состоянии воспроизведено: ответы заполнены, область есть, задачи нет; `QuestionnaireGenerationCreate` выбрасывает `Masked edit region is fully covered by protected regions` | Для общей концепции исключены выдуманные прямоугольники защиты. Используются только области, которые пользователь действительно выделял. Перекрытие настоящими защищёнными областями возвращает понятный 422 до создания задачи |
| Ошибка удаления объекта | Тот же конфликт масок воспроизведён для удаления; дополнительно найдены противоречащие удалению правила сохранения геометрии | Отдельная политика удаления; точное сохранение изображения вне выделения. Повтор failed-задачи сохраняет ссылку на принятый объект до атомарной привязки новой задачи |
| Ошибка или потеря ответа запуска | Раньше область сбрасывалась перед POST, после ошибки первый вопрос открывался снова; старый ID принятой генерации мог выглядеть как результат правки | Область сохраняется до серверного binding. После ошибки клиент сверяет состояние; новая найденная задача продолжается без повторного POST. При недоступной сверке повтор заблокирован. Сохранение ответов блокирует строку проекта; устаревший PUT не может заменить привязанную задачу |
| Дом слишком велик относительно участка | Расчёт 200 / 2 = 100 м² уже существовал, но назывался только ориентиром; в последующих правках его не было | Промпт явно задаёт пятно на земле, отношение площадей 10:1 и оставшуюся долю земли 90% для участка 10 соток. Эти значения перенесены в правки общей концепции; площадь кадра отделена от площади участка |
| Вместе с живой изгородью появляется забор | В ответах о размещении есть «вдоль забора» / «внутри забора» | Эти слова трактуются как ориентир границы, а не заказ нового ограждения. Если выбраны оба объекта — оба допускаются; существующий забор на исходном фото сохраняется без отдельной команды удаления |
| Камин и труба | Правило требовало связь только при видимом камине | «Да» на камин требует наружную трубу на кровле основного дома; показывать сам камин и придумывать интерьер не требуется. При удалении дома эти требования отключаются |

Исправление старых проектов не требует ручного SQL или новой миграции. Сохранённые ответы и исходные эскизы не изменялись при диагностике. Старые guessed locks остаются совместимыми данными, но для общей концепции не используются как точная маска. Legacy-последовательный режим сохраняет свои существующие lock regions.
